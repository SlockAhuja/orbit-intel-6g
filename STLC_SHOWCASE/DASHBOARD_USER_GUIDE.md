## 1. Quick Launch Instructions

To launch the interactive dashboard on your local machine:

```powershell
# In PowerShell or Bash at the project root:
streamlit run dashboard/app.py
```

Open your browser to: `http://localhost:8501`.

---

## 2. Navigating Demonstration Modes

The dashboard features a persistent sidebar with a global **Demonstration Mode** toggle:

- **Mode A: Live Physical Simulation:**
  - Connects directly to the live Python discrete-time physics simulator (`NetworkSimulator`).
  - Allows you to step forward in time, inject environmental perturbations (rain, shadowing flutter), and evaluate instant routing decisions.
- **Mode B: Recorded Demonstration / Benchmark Replay:**
  - Loads verified experimental results from the 400 Monte Carlo campaign episodes (`phase4_benchmarking/`) and 415 sensitivity sweep runs (`phase5_robustness/`).
  - Displays statistical distributions, confidence intervals, hypothesis tests ($p < 10^{-15}$), and ablation studies.

## 3. Step-by-Step Module Walkthrough

### Module 1: Main Overview & Executive Summary
- **What to observe:**
  - 4 Key Metric Cards at the top showing the 4-tier constellation, served terminals, sub-10 ms URLLC latency, and the **92.4% reduction in ping-pong handovers**.
  - 4-Tier Constellation Architecture Grid summarizing technical parameters for Space (LEO), Stratosphere (HAPS), Aerial (UAV), and Terrestrial (TBS) tiers.
- **Judge Action:**
  - Note the data provenance badge indicating reproducible seed `42` and git branch `stlc_dashboard_first`.

### Module 2: Interactive 3D SAGIN Topology
- **What to observe:**
  - 3D Plotly interactive globe with Earth WGS84 surface, orbital satellites, stratospheric platforms, UAVs, base stations, and user terminals.
- **Judge Action:**
  - Use mouse to rotate, zoom, and pan around the 3D constellation.
  - Switch the radio button between **Access Network Nodes** and **User Terminals (UE)**.
  - Select different nodes (e.g. `SAT-01`, `HAPS-01`, `TBS-01`) to inspect their live telemetry card (altitude, Tx power, carrier bandwidth, instantaneous load, ECEF coordinates, and orbital speed).

### Module 3: Satellite Telemetry & RF Tracking
- **What to observe:**
  - Keplerian astrodynamics and physical RF propagation tracking.
  - Topocentric elevation angle $\theta(t)$ with the 10° critical cutoff threshold.
  - Dynamic Doppler shift curve showing the continuous S-band frequency shift ($f_D \in [-48, +48]\text{ kHz}$) caused by the 7.56 km/s orbital velocity.
- **Judge Action:**
  - Select `SAT-01` and `UE-01` to view the slant range and Doppler trajectory over a 40-second pass.

### Module 4: Predictive Intelligence Center
- **What to observe:**
  - Multi-horizon forecasting ($H \in \{1, 3, 5, 10\text{ s}\}$) generated by the trained Dual-Uncertainty Predictor (`models/capro_predictor.joblib`).
  - Shaded cyan envelope representing the **90% Calibrated Prediction Interval** $[\hat{q}_{05}, \hat{q}_{95}]$.
  - Red outage threshold line at $3.0\text{ dB}$.
  - Impending Outage Early-Warning Banner triggering whenever $\hat{q}_{05} < 3.0\text{ dB}$.
- **Judge Action:**
  - Switch the lookahead slider between 1s, 3s, 5s, and 10s to observe the widening uncertainty envelope.
  - Inspect the table breaking down Aleatoric vs. Epistemic uncertainty.

### Module 5: CAPRO Intelligence Center
- **What to observe:**
  - Candidate Node Feasibility Table evaluating all nodes against hard constraints ($P_{\text{outage}} \le 10^{-4}$, delay $\le 10\text{ ms}$, departure buffer $\ge 12\text{ s}$).
  - Transparent Decision Audit Card displaying the exact natural language explanation behind the serving node assignment.
- **Judge Action:**
  - Select different user terminals (e.g. `UE-01` [URLLC] vs `UE-03` [eMBB]) to verify that URLLC traffic is routed to low-latency terrestrial/aerial nodes while eMBB utilizes high-capacity satellite/stratospheric links.

### Module 6: Satellite Handover Live Demonstration
- **What to observe:**

  - SAT-01 setting below 10° while SAT-02 rises.
  - Side-by-side comparison between **Proposed CAPRO** and **M1 Reactive Baseline**.
- **Judge Action:**

    - At $t=23\text{ s}$: Observe CAPRO detecting $T_{\text{vis}} \le 12\text{ s}$ and proactively transferring traffic to rising SAT-02 with **0.0% packet drop**.
